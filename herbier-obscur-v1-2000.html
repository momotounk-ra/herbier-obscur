Encyclopédie botanique évolutive

Herbier Obscur

Un index botanique consultable, construit progressivement à partir de données taxonomiques publiques. Cette première version charge jusqu’à 2 000 noms d’espèces végétales acceptés dans le référentiel GBIF.

Les enregistrements sont des noms taxonomiques acceptés de rang « espèce », et non des observations de terrain. Le référentiel peut évoluer avec les mises à jour de GBIF.

Source et attribution
Données taxonomiques issues de GBIF, via son API publique : documentation de l’API. Les noms, classifications et statuts sont fournis par le référentiel GBIF. Herbier Obscur n’est pas affilié à GBIF.

Important : cette version est un index de noms et de classifications. Elle ne constitue pas une base vérifiée des propriétés médicinales ou toxiques. Ne goûte, ne manipule et ne cultive pas une plante inconnue pour la tester.
